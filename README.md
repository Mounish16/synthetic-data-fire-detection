MSc Project – Optimising Synthetic Data Use in AI for Industrial Fire Detection  

This repository is to support the MSc project **“Optimising Synthetic Data Use in AI for Industrial Fire Detection”** submitted to the University of Bristol, Faculty of Engineering, Department of Engineering Mathematics, 2025.  

The repository contains all scripts and configuration files required to reproduce the experiments, results, and figures presented in the dissertation.  



---

## Data  

Two datasets were used in this project:  

- **Real Dataset – DFireDataset**: [DFireDataset GitHub](https://github.com/gaiasd/DFireDataset?tab=readme-ov-file)  
- **Synthetic Dataset – SYN-FIRE (Roboflow)**: [Roboflow Synthetic Fire-Smoke](https://universe.roboflow.com/yunnan-university/synthetic-fire-smoke)  

 These datasets cannot be redistributed directly due to licensing.
